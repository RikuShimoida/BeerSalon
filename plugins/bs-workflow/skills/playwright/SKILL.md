# Playwright MCP 運用ルール

## 概要

Playwright MCP サーバーを使い、GitHub PR の変更内容が受入条件を満たしているかを、ブラウザ操作によって確認する。

## 厳守事項

- テスト対象は、ユーザーが既に起動している localhost のURLまたはポートを利用すること
- 勝手に別ポートを推測してアクセスしないこと
- localhost のURLまたはポートが不明な場合は、ユーザーに確認すること
- ユーザーが実施計画にOKを出すまでは、Playwright MCPによるブラウザ操作を開始しないこと
- 不具合を見つけた場合は、修正せずに再現手順・期待結果・実際の結果を報告すること

## 実施手順

1. GitHub PR `$ARGUMENTS` の内容を確認する
2. 変更内容・受入条件・影響範囲を整理する
3. Playwright MCPで確認するE2Eテスト計画を示す
   - 確認対象の画面
   - 操作手順
   - 期待結果
   - 重点的に見る観点
4. ユーザーが計画にOKを出したら、Playwright MCPでE2E確認を実施する
5. 確認結果を報告する
   - 実施した操作
   - 成功した項目
   - 失敗した項目
   - 不具合がある場合の再現手順
   - 追加で確認した方がよい観点
