## PRコードレビュー

引数: `$ARGUMENTS`（PR番号。例: 123）

### 手順

#### 1. PR情報の取得

以下のコマンドでPRの内容を取得する:

```bash
# PR概要の取得
gh pr view $ARGUMENTS

# PR差分の取得
gh pr diff $ARGUMENTS
```

#### 2. コードレビューの実施

- **設計整合性**: プロジェクトの設計ドキュメント（存在すれば）との整合
- **型安全性**: 型定義・バリデーションスキーマの妥当性
- **セキュリティ**: SQLインジェクション、XSS、認証・認可の漏れ
- **パフォーマンス**: N+1クエリ、不要な再レンダリング、インデックス不足
- **コード品質**: 命名規則、関心の分離、重複コード
- **エラーハンドリング**: 境界値・異常系の考慮
- **テスト**: テストの網羅性・妥当性

**重要**: コードの修正は一切行わない。レビューコメントの作成のみ。

#### 3. レビュー結果のPRコメント投稿

レビュー結果を以下のフォーマットでPRにコメントする:

```bash
gh pr comment $ARGUMENTS --body "$(cat <<'EOF'
## 🔍 コードレビュー

### 総合評価
<!-- Good / Needs Discussion / Request Changes のいずれか -->

### 良い点
<!-- 設計やコードで良かった点を箇条書き -->

### 指摘事項
<!-- 以下のフォーマットで指摘 -->
<!-- - **[重要度: High/Medium/Low]** 対象ファイル:行番号 — 指摘内容 -->

### 提案・改善案
<!-- 必須ではないが、より良くなる提案を箇条書き -->

---
🤖 This review was generated by Claude Code
EOF
)"
```

#### 4. ユーザーへの報告

PRにコメントを投稿した旨をユーザーに報告する:
- PR番号とURL
- 指摘事項の概要（件数と重要度の内訳）
