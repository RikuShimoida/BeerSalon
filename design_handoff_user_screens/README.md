# Handoff: Beer Salon — ユーザー画面リデザイン（Dark Taproom）

## Overview
Beer Salon（クラフトビール特化の検索・投稿・集客プラットフォーム / `apps/web`）のユーザー画面を、統一されたビジュアル方向性「**Dark Taproom**」で再設計したモックです。既存デザインの主要課題であった「ヘッダー・フッターの帯色と本文コントラストの不一致」「トップだけダーク・他ページはライトという不統一」を、**全画面を一つのダーク×アンバー基調にまとめる**ことで解決しています。

対象リポジトリ: `RikuShimoida/BeerSalon`（Next.js App Router + Tailwind CSS + Supabase）。

## About the Design Files
このバンドルに含まれる HTML ファイルは、**HTML で作成したデザインリファレンス（プロトタイプ）**です。意図した見た目・レイアウト・振る舞いを示すもので、そのまま本番コードとしてコピーするものではありません。

タスクは、これらのデザインを**対象コードベースの既存環境（Next.js App Router + React + Tailwind CSS）で、既存のパターン・コンポーネント・ライブラリを使って再現する**ことです。具体的には:
- 既存の `apps/web/src/components/` の構造（`bar/`, `home/`, `layout/`, `search/` 等）を踏襲する
- 配色は Tailwind + CSS 変数（`globals.css` の `:root` / `themes/`）に落とし込む。現状の壊れているトークン（`--background` 等が `hsl()` 未ラップで透明化している問題）を、この機会に実値で機能するよう整理する
- lucide-react アイコン、Next.js `<Image>`、既存の `SearchForm` / `BarCard` / `Header` / `Footer` を置き換える形で適用する

## Fidelity
**High-fidelity (hifi)** です。最終的な配色・タイポグラフィ・余白・角丸・影・状態表現まで作り込んでいます。開発者は既存ライブラリ・パターンを使い、**ピクセル単位で忠実に再現**してください。ただし写真部分はストライプのプレースホルダ（`店舗写真` / `投稿写真` などのラベル付き）で表現しており、ここには実際の画像（Supabase Storage の店舗・投稿画像）が入ります。

### Typography
Google Fonts で読み込み:
- **Zen Old Mincho**（serif, 700/900）— 見出し・店名・PR文・記事本文。ブランドの落ち着いた世界観の核。
- **Zen Kaku Gothic New**（sans, 400/500/700/900）— UI本文・ラベル・ボタンのデフォルト。
- **Archivo**（sans, 500–800）— ラテン文字の見出し・ロゴの "Salon"・オーバーライン（`letter-spacing` を広めに, `text-transform: uppercase`）・カウンタ数字・monospace風のキャプション。
  - **運用ルール**: Archivo は**和文グリフを持たない**ため、`.font-archivo`（実装は `apps/web/src/app/globals.css`）は**ラテン文字（英字・数字）要素に限定**して適用する。日本語を含む要素に当てると和文がフォールバックフォントへ落ちてラテン字と和字でフォントが混在するため、和文を含む見出し・本文は Zen Old Mincho / Zen Kaku Gothic New を使う。

代表サイズ:
- モバイル ヒーロー見出し: 25–27px / 900 / line-height 1.25–1.35（Zen Old Mincho）
- PC ヒーロー見出し: 34–42px / 900
- セクション見出し: 17–20px / 700（Zen Old Mincho）
- カード店名: 15px / 700
- 本文: 13.5–16.5px / line-height 1.6–2.1
- ラベル・キャプション: 11–12.5px、オーバーラインは `letter-spacing:.16–.28em` uppercase

### Radius
- 端末フレーム: 44px（外）/ 34px（画面）
- カード: 16px、大きめパネル: 18–22px
- 入力欄・ボタン: 12–14px
- チップ・ピル: 999px
- サムネイル小: 10–12px

### Shadow
- カード浮き: `0 40px 80px -30px rgba(40,25,8,.6)`（端末）/ `0 50px 100px -40px rgba(40,25,8,.65)`（PCパネル）
- 内側ハイライト: `0 0 0 2px rgba(255,255,255,.04) inset`

### Spacing
8px グリッド基調。カード内パディング 13–18px、セクション左右 20px（モバイル）/ 32–40px（PC）、要素間 gap 8–16px。

## Screens / Views（詳細）

### 共通レイアウト
- **ログイン後**: 上部固定ヘッダー（ロゴ左 / 通知ベル・マイページ・ログアウトを右、アイコンは `#241a0e` 丸背景 + アンバー薄ボーダー、通知は赤バッジ）。モバイルは下部固定ボトムナビ4アイコン（お気に入り★ / タイムライン / 投稿＋（中央FAB, アンバーグラデ丸）/ 閲覧履歴）。PC はヘッダーに横ナビ + 「投稿する」プライマリボタン。
- **ログイン前**（認証画面）: ヘッダー/フッターなし。

### 1a / 2a — トップ/検索
- **Purpose**: キーワード/市町村/カテゴリ/産地で店舗検索、地図とリスト連動。
- **モバイル(1a)**: ヒーロー（オーバーライン + 明朝見出し「今夜の一杯を、この街で見つける。」）→ 検索バー（入力欄 + アンバー丸検索ボタン）→ カテゴリチップ（選択中は `#e0a341` 塗り + `✓`、未選択は `#2c2013` + 薄ボーダー）→ 地図（グリッドパターン + アンバーのピン `border-radius:50% 50% 50% 0; transform:rotate(-45deg)`）→ 店舗カードリスト（写真 + 店名 + 県市 + タグ）→ 人気カテゴリ横スクロール → ボトムナビ。
- **PC(2a)**: ヘッダーに横ナビ。ヒーロー帯の右に検索カード（`#211810`）を配置。その下を**2カラム**（左 620px 固定マップ / 右スクロール2列の店舗グリッド）。最下部に人気カテゴリ 4カラムグリッド（150px高タイル）。

### 3a / 3b — 店舗詳細（基本情報）
- フルブリードの写真ヒーロー（上下グラデオーバーレイ、カルーセルドット）。上部に戻る/シェア/お気に入り（アンバー丸）。ヒーロー下端に店名（明朝）+ 所在地・営業状況。
- 固定タブ: 基本情報 / メニュー / 投稿 / お店から / クーポン（PCは +イベント、+タグ付き投稿）。アクティブはアンバー文字 + 下線。
- コンテンツ: PR文（明朝リード + 本文）、営業時間カード（曜日レンジ + 時刻、定休日）、情報行カード（住所/電話（アンバー）/支払い、区切り線）、SNSボタン（Instagram / X）。
- モバイル下部固定アクション: お気に入り（丸）+「このお店に投稿する」（アンバーグラデ幅広）。PCは2カラム（左: PR + タグ + ミニマップ / 右 300px: 営業時間・情報・SNS）。

### 4a / 4b — 店舗詳細（メニュー）
- 見出し「Beers」（Archivo 太字 + 罫線 + On Tap 数）。ビールカード（左に縦長ボトル写真 76–84px、右にビール名 / スタイル・ABV（アンバー）/ 説明 / 🏭醸造所・産地）。
- 区切り後「Meals」。料理カードグリッド（写真 + 料理名 + 価格）。モバイル2列 / PC Beers 2列・Meals 4列。

### 5a / 5b — タイムライン
- タブ「フォロー中 / みんな」。投稿カード: ユーザーアバター（グラデ丸）+ ニックネーム + 時刻 → 写真グリッド（1〜4枚, 2fr:1fr 分割等）→ 本文 → 店舗リンクピル（アンバー、ピンアイコン）→ タグ（`#c79241`）→ アクション（いいね赤 / コメント / シェア）。
- PC は中央フィード + 右 240px サイド（人気タグ、投稿促進カード（アンバーグラデ背景 + 濃茶ボタン））。

### 6a / 6b — マイページ
- プロフィール帯（グラデ背景 + 発光円）: アバター + ニックネーム（明朝）+ 一言 + 投稿/フォロー/フォロワー数 + 「プロフィールを編集」。
- タブ: 投稿 / 持っているクーポン。投稿は正方形3列グリッド。クーポンは**チケット型カード**（左に破線区切りのアンバースタブ + COUPONラベル、右に見出し/対象店舗/期限/利用ボタン）。使用済みは opacity 0.6 + グレースタブ +「使用済み」。

### 7a / 7b — 投稿作成
- 上部バー: ✕ + タイトル + 「投稿する」プライマリ（PCは +キャンセル）。
- フィールド: お店選択（ピン + 店名 + ▼）/ 写真（最大4枚、サムネに削除✕、追加は破線 + ＋）/ 本文（プレースホルダは `#5f5138`）/ タグ（選択済みチップに✕、+タグ追加は破線）。
- PC は写真を左380px（大1 + 小3）、入力を右2カラム。

### 8a / 8b — 通知
- 「すべて既読にする」。Today / Yesterday でグルーピング。種類別アイコン丸背景（いいね=赤系 / フォロー=アンバー系 / クーポン・記事=`#241a0e`）+ タイトル（強調名は `<strong>`）+ 補足 + 日時 + 右シェブロン。**未読**はモバイル=左3pxアンバーバー + 薄アンバー背景、PC=右アンバードット + アンバー枠カード。

### 9a / 9b — 記事
- 店舗オーバーライン + 大見出し（明朝）+ いいね(赤)・投稿日・シェア。画像（最大3枚）。本文は **Zen Old Mincho / line-height 2.0前後** で可読性重視。末尾に関連店舗導線カード（サムネ + 店名 +「店舗を見る」）。PC はフルブリードのタイトルヒーロー + 中央660px幅の記事カラム。

### 10a / 10b — お気に入りバー
- 店舗カード（右上に★解除トグル = `rgba(15,11,6,.6)` 丸 + アンバー★）。モバイル1列 / PC 3列。PCには参考として**空状態**（破線枠 + ★アイコン丸 +「まだお気に入りがありません」+「お店をさがす」ボタン）も掲載。

### 11a / 11b / 11c — ログイン / 新規登録
- **11a ログイン(モバイル)**: 上部ストライプ + 発光円のヒーロー（ロゴ大 + タグライン）→ メール/パスワード（表示トグル目アイコン）→ ログイン（アンバーグラデ）→ 新規登録 / パスワード忘れリンク。
- **11b 新規登録(モバイル)**: ロゴ + 「新規登録」→ メール → パスワード + **強度メーター**（4分割バー, 満たすほどアンバー）+ ヒント文 → 登録ボタン → 「または」区切り → Googleで登録 / Xで登録 → ログインへのリンク。
- **11c ログイン(PC スプリット)**: 左400px にブランドビジュアル（ストライプ + グラデ + ロゴ + 明朝コピー）、右にフォーム（「おかえりなさい」）。

### 12a / 12b — 閲覧履歴
- Today / This Week グルーピング。軽量リスト行（サムネ56–60px + 店名 + 県市 + シェブロン）。モバイル1列 / PC 2列カード。

## Interactions & Behavior
- **検索**: キーワードEnter/ボタンで発火。市町村・産地は select、カテゴリは複数選択トグル（OR検索）。マップと一覧は**同一データソース**（`getBars()` の結果を親で1回取得し両者へ配る）。マップは表示ピン群に `fitBounds`（1件は中心、0件は市町村代表座標/現在地）。
- **タブ**: 店舗詳細・マイページのタブ切替。アクティブ = アンバー文字 + 下線 / ドット。
- **お気に入り / いいね**: トグル（★の塗り、いいねは赤の塗り + カウント）。
- **クーポン**: 取得（未取得→取得済み非活性、期限外/上限で非活性ラベル）、利用（`is_used=true`, `used_count+1`、使用済みバッジ）。トーストで完了表示（Sonner 想定）。
- **投稿**: 写真最大4枚、店舗必須。送信でタイムラインへ反映。
- **ホバー**: リンク/カードは軽い opacity 低下 or リフト（`transition .2–.3s`）。
- **レスポンシブ**: モバイルファースト。PCで 2カラム（マップ+リスト、詳細の情報サイド、タイムラインのサイド）、認証はスプリット。

## State Management（既存 `apps/web` に準拠）
- 検索状態（q / city / categories / origin）を URL クエリと同期（真実の源は URL、ブラウザバック追従）。
- `bars` は親で取得し map + list に配布、`isLoading` でスケルトン表示。
- 認証は Supabase Auth（middleware でガード）。通知未読数はヘッダーで取得。
- クーポン/いいね/お気に入り/フォローは Server Actions（`actions/` 配下）で楽観更新 + トースト。

## Assets
- **アイコン**: すべて lucide-react 相当のストロークアイコン（ベル / ユーザー / 検索 / ピン / 時計 / ビールジョッキ / 星 / ハート / 吹き出し / プラス 等）+ ブランドSNS（Instagram / X / Facebook / LINE, 既存 `components/icons/` を利用）。モックではインラインSVGで再現。
- **画像**: ストライプのプレースホルダ（`店舗写真` `投稿写真` `記事画像` ラベル）。実装では Supabase Storage の店舗・投稿・記事画像に差し替え。未設定時のフォールバックはビールジョッキアイコン + `#muted` 面。
- **ロゴ**: 既存 `/beer-salon-logo.svg`。モックではテキストロゴ（Zen Old Mincho "Beer" + Archivo "Salon"）で表現。実装は既存SVGを使用可（配色をアンバー基調に合わせる）。
- **フォント**: Google Fonts（Zen Old Mincho / Zen Kaku Gothic New / Archivo）。Next.js の `next/font` での読み込みを推奨。
