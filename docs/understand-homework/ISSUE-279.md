### Spring Boot 翻訳

今回は Next.js / React のコードは一切変更していない。理解チェックスキルの手順書（`SKILL.md`）、運用ドキュメント（`README.md`）、GitHub Actions ワークフロー（`claude.yml`）という、開発ワークフロー側の設定・ドキュメントのみの変更。

- **GitHub Actions ワークフロー（`claude.yml`）**: Spring Boot に直接対応はない。強いて言えば Jenkins の `Jenkinsfile` や Maven の CI 設定に近い、CI/CD パイプライン定義。`on:` のイベントトリガーは「どのイベントでビルドを起こすか」の設定に相当。
- **スキル定義（`SKILL.md`）**: アプリのロジックではなく Claude への手順書（ランブック）。Java で言えば実行コードではなく `CONTRIBUTING.md` や運用 Wiki に近い。
- **Spring Boot 開発者として注意すべき違い**: `@Entity` も `@Controller` も Prisma も登場しない。「動くコード」ではなく「運用の取り決め」を変更した点が通常の機能実装と根本的に異なる（テストコードが不要だったのもこのため）。
