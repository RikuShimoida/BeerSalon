## 作業完了時の品質チェック（順序厳守）

作業完了の報告前に、以下を **必ずこの順序で** 実行すること。

### 1. フォーマットを実行する

- `pnpm format`

### 2. lint を実行し、エラーがあれば必ず修正する

- `pnpm lint`
- 修正が発生した場合は再度フォーマットを実行する

### 3. Playwright MCP サーバーで受入条件の動作確認を行う

- 受入条件を満たしていることを確認できない場合は作業完了としてはならない
- テストの対象は、既に起動している localhost のポートを利用すること

### 禁止事項

- Playwright MCP による受入確認 **前に** コミット・プッシュ・PR 作成を行うこと
- フォーマットや lint 修正 **後に** コミットせずに作業を終了すること

## 報告義務

品質チェック完了後、必ず以下を報告すること。

1. **何を修正したのか**
2. **なぜその修正が必要だったのか**
3. **どのファイルを変更したのか**
4. **受入条件をどのように満たしたか**
